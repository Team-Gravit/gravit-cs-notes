# 과목별 목차 개편안

`docs/` 레퍼런스 모음(총 332건)의 주제 분포와 면접·자격증 출제 근거를 바탕으로,
CS 전공 학생 + 개발자 취업 준비생을 대상으로 한 과목별 목차를 재설계한 것이다.

<br>

## 공통 설계 원칙

1. **면접 빈출 우선** — 국내 기술면접(신입 백엔드/프론트 공통)에서 반복 질문되는 주제를 필수 유닛으로 승격한다.
   - 예) TCP 흐름·혼잡제어, 트랜잭션 격리 수준, 해시 충돌, "URL 입력 시 일어나는 일"
2. **자격증 커버리지** — 정보처리기사·SQLD·정보보안기사 출제 범위와 겹치는 주제는 반드시 포함한다.
3. **학습 흐름(선수 지식) 순서** — 각 유닛은 앞 유닛만으로 이해 가능하도록 배치한다.
4. **과목 간 연계 명시** — 같은 주제를 두 과목에서 중복 서술하지 않고 상호 참조한다.
   - 예) 힙(자료구조) ↔ 힙 정렬(알고리즘), TLS(네트워크) ↔ 인증서 체인(웹보안), 커넥션 풀(DB) ↔ TCP 핸드셰이크(네트워크)
5. **교과서식 주제 축소** — 물리 계층, 토폴로지, 무선 네트워크처럼 면접·실무 활용도가 낮은 주제는
   개요 유닛에 흡수하거나 후순위로 미룬다.

> ⚠️ 조치 구분: **유지**(그대로) / **보강**(내용 추가) / **통합**(여러 유닛 합침) /
> **신규**(현재 없음) / **이동**(순서 변경). "기존" 열은 현재 실제 파일 기준이다.
> CLAUDE.md의 주제 맵은 실제 파일과 어긋나 있으므로 이 문서 확정 후 함께 갱신해야 한다.

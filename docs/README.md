## 활용 방법

1. **기존 노트 개선 시** — 각 문서의 `UNIT 매핑` 표에서 해당 unit 번호에 대응하는 링크를 먼저 확인한다.
2. **신규 노트 작성 시** — `1. 기술 블로그`에서 개념 설명과 도식을, `3. 자격증`에서 출제 포인트와
   용어 정의를 가져와 노트의 근거로 삼는다.
3. **문제 생성 연계** — 자격증 기출 자료는 개념노트 기반 문제 생성 시 난이도·출제 형태의 참고 기준이 된다.

<br>

## ⚠️ 주의 사항

- 링크는 웹 검색 결과를 기반으로 수집했으며, **개별 페이지의 접속 가능 여부와 내용 정확성까지
  전수 검증하지는 않았다.** 노트에 반영하기 전 원문 확인이 필요하다.
- 개인 블로그(velog, GitHub Pages 등) 자료는 오류나 개인 해석이 섞여 있을 수 있으므로,
  **공식 문서·서적·위키와 교차 검증**한 뒤 사용한다.
- 서적·유료 강의 링크는 상세 페이지만 연결했다. 본문 내용을 그대로 옮기는 것은 저작권 문제가
  있으므로, **개념을 재구성해 작성**한다.
- 나무위키·위키백과는 빠른 개요 파악용으로만 쓰고, 노트의 최종 근거로는 삼지 않는다.
